# Experiment materials

This folder preserves the original PsychoPy Builder source and supporting files needed to document the experiment as administered.

Included materials cover the 24 experimental post images, three practice images, prebunk/control information sheets, interface assets, counterbalancing files, and the post-task political questionnaire.

The original PsychoPy source is retained as provenance. Some internal component or variable names predate the revised manuscript terminology; see ../docs/TERMINOLOGY.md.

Raw participant exports, JASP files, generated machine-specific scripts, duplicate ODS files, and font binaries are not included in this public release.
