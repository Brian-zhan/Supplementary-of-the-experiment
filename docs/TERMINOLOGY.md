# Terminology

The manuscript-facing outcome is **perceived rhetorical bias**.

Historical experiment and analysis files may contain legacy internal labels such as `misleadingness`, `discrimination`, or `true_or_false`. These identifiers are retained only where needed to preserve provenance and reproducibility.

They should not be interpreted as evidence that the revised study treats the item sets as verified true versus false information. The current interpretation concerns differentiation between the study's target-rhetoric and comparison item sets.

Reader-facing documentation should use **perceived rhetorical bias** or **rhetorical bias**.
